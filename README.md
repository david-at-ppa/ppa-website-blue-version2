# Prime Path Advisory — Marketing Website

A purpose-built authority site for [Prime Path Advisory](https://www.primepathadvisory.com), a premium tax advisory firm serving $1M+ earners. The site qualifies leads through an income-based flow and books them onto a strategy call with a closer.

## About this repository

This repo is a duplicate of the main [`ppa-website`](https://github.com/david-at-ppa/ppa-website) codebase. It exists to develop a **blue-themed variant** of the current marketing site without affecting the production heritage-themed site. Feature work and design experiments for the blue version happen here first.

## Stack

- **Framework:** Next.js App Router + TypeScript
- **Styling:** Tailwind CSS + shadcn/ui
- **Deployment:** Vercel
- **Booking backend:** GoHighLevel (embedded calendar)
