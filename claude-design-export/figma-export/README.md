# Prime Path Advisory — Figma Export

## What's in this package

- bundle/ — 7 self-contained HTML files (one per page)
  - index.html (Home)
  - about.html (About Us)
  - services.html (Services)
  - blog.html (Blog)
  - contact.html (Contact Us)
  - reviews.html (Client Reviews)
  - thank-you.html (Booking confirmation page)

Each HTML file is fully self-contained — all CSS, JS, images, and fonts inlined. They work offline and open in any browser.

## How to import into Figma

### Option A: html.to.design plugin (RECOMMENDED — best fidelity)

1. Open Figma, go to **Plugins** → search **"html.to.design"** → install (free tier covers personal use).
2. In a Figma file, run the plugin (Plugins → html.to.design).
3. **Drag and drop** each HTML file from the bundle/ folder into the plugin window — OR upload via the plugin's file picker.
4. Plugin will convert to editable Figma frames with real layers, text, shapes, and auto-layout.
5. Repeat for each of the 7 pages.

### Option B: Use as a screenshot reference

1. Open any of the bundle/ HTML files in Chrome/Safari at 1440px wide.
2. Use a full-page screenshot tool (Chrome: F12 → Cmd+Shift+P → "Capture full size screenshot").
3. Drag the resulting PNG into Figma as a reference image.

## Notes

- Pages are designed at a 1440px desktop breakpoint.
- Fonts used: Fraunces (display serif), Inter (body), JetBrains Mono (eyebrow / labels).
- Brand colors: #f3f2ee (bone), #0a1929 (ink), #14a06d (green), #c9a961 (gold).
